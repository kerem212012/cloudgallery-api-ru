# CloudGallery API

## Результат урока

В проекте реализован API для загрузки изображений в JPEG, PNG и WebP размером до 5 МБ.
Формат проверяется по сигнатуре байтов, а не только по имени файла и MIME-типу.
Файлы получают безопасные ключи, не зависящие от исходного имени.

Хранилище подключается через единый контракт и dependency FastAPI. Доступны две реализации:

- `local` — сохраняет файлы в папку `uploads/` и работает без облачных ключей;
- `s3` — использует S3-совместимое хранилище, удаление и временные ссылки.

## Требования

- Python 3.12 или новее;
- [uv](https://docs.astral.sh/uv/).

Команды ниже выполняются из корня проекта.

## Установка

Создай локальный файл настроек и установи зависимости из lock-файла:

```bash
cp .env.example .env
uv sync --frozen --dev
```

В PowerShell команда копирования выглядит так:

```powershell
Copy-Item .env.example .env
```

## Запуск

Локальный режим включен по умолчанию и не требует аккаунта или S3-ключей:

```bash
uv run fastapi dev app/main.py
```

После запуска API доступен по адресу `http://127.0.0.1:8000`, а интерактивная документация — по адресу `http://127.0.0.1:8000/docs`.

Проверить состояние сервиса можно так:

```bash
curl http://127.0.0.1:8000/health
```

Для S3 укажи `STORAGE_BACKEND=s3`, bucket, endpoint и ключи в `.env`. Реальные ключи не добавляй в репозиторий.

## Тестирование

Запусти весь набор тестов:

```bash
uv run pytest
```

Тесты проверяют загрузку, список и удаление изображения, безопасный ключ, ограничение размера, допустимые типы и отклонение файла с неверной сигнатурой.
