# Задание

- Принимай `UploadFile` только для JPEG, PNG и WebP до 5 МБ; подтверждай формат по сигнатуре байтов, а не только по имени и `Content-Type`.
- Генерируй безопасный ключ независимо от исходного имени файла.
- Опиши единый протокол хранилища и локальную реализацию.
- Добавь S3-реализацию с `upload_fileobj`, удалением и временной ссылкой.
- Выбирай backend через settings/dependency, не через условие в маршруте.
- Проверь локальный режим без облачных ключей и `uv run pytest`.
- Добавь тест: текстовый файл с именем `.png` и MIME `image/png` должен получить `415`.
